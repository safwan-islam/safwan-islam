### E-Commerce Recommendation Engine

<img src="https://img.shields.io/badge/Status-In_Development-EAB308?style=flat-square"/>

An end-to-end applied machine learning project focused on personalized e-commerce product recommendations through hybrid recommendation algorithms.

**Project objectives:**

- Neural collaborative filtering using PyTorch user and product embeddings.
- Content-based recommendations using TF-IDF and cosine similarity.
- Hybrid recommendation ranking combining multiple recommendation strategies.
- Model evaluation using Precision@K, Recall@K, NDCG@K, and Hit Rate@K.
- FastAPI-based model inference and interactive React dashboard.
- Docker deployment, automated testing, and CI/CD pipelines.
